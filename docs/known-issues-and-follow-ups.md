## P2 · 默认阈值命中 0 条

2026-09-06 实测 `/browse/movie` 第一页 100 条：

| 阈值 | 命中 |
|---|---|
| 8 / 8 / 2024 | **0** |
| 8 / 8 / 不限年份 | 7 |
| 7 / 7 / 2024 | 22 |
| 6 / 6 / 2024 | 33 |
| 不限分 / 2024 | 53 |

该页 ≥2024 的有 53 条，但没有一条豆瓣或 IMDb 达到 8.0（豆瓣最高 8.8、IMDb 最高 8.3，都是老片）。
默认值是按需求定的，不是 bug，面板可随时调。若长期不好用，考虑把默认降到 7.0。

## P2 · 只处理当前页

分页在服务端，每页固定 100 条、共 100 页。扩展不会替你翻页。
跨页聚合的方案评估见 `design.md` 的「明确不做」。

## P3 · 全页无命中时整页压暗

命中 0 条时 100 行全部半透明，观感上像页面坏了。面板的计数（`本页 100 条，符合 0 条`）
是唯一的区分信号。当前保持行为一致、不做特例；若实际使用中困扰，可加「命中为 0 时不压暗」的规则。

## P3 · 角标识别依赖背景色类

主判据是 `bg-[#007711]`（豆瓣）和 `bg-[#F5C518]`（IMDb）。站点改配色需要同步更新。
已有两道缓解：角标文本前缀兜底；整页 ≥10 条却识别不出任何评分时，面板显示改版警告。

## P3 · 年份来自发布名

发布名不含四位年份的条目永远不会命中。2026-09-06 实测 100/100 都能提取到，风险很低。
