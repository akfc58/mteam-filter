## P2 · 默认阈值命中过少（已解决）

初版默认 8 / 8 / 近两年，2026-09-06 实测 `/browse/movie` 第一页命中 **0 条**。
2026-09-07 默认调整为 **7 / 7 / 近五年**，同页命中 **27 条**。

同页实测对照（100 条，评分与年份均 100% 解析成功）：

| 阈值 | 命中 |
|---|---|
| 7 / 7 / 近五年（当前默认） | **27** |
| 7 / 7 / 近两年 | 22 |
| 8 / 8 / 近五年 | 0 |
| 8 / 8 / 近两年 | 0 |

结论：瓶颈在分数不在年份。该页近五年的有 59 条，但把年份放宽到五年后 8 分阈值依然是 0 命中，
说明这个分区的新片豆瓣和 IMDb 普遍在 8 以下。7 分是这个站比较合适的档位。

## P2 · 只处理当前页

分页在服务端，每页固定 100 条、共 100 页。扩展不会替你翻页。
跨页聚合的方案评估见 `design.md` 的「明确不做」。

## P3 · 全页无命中时整页压暗

命中 0 条时 100 行全部半透明，观感上像页面坏了。面板的计数（`本页 100 条，符合 0 条`）
是唯一的区分信号。当前保持行为一致、不做特例；调到 7 分后触发概率已经很低。
若实际使用中仍有困扰，可加「命中为 0 时不压暗」的规则。

## P3 · 角标识别依赖背景色类

主判据是 `bg-[#007711]`（豆瓣）和 `bg-[#F5C518]`（IMDb）。站点改配色需要同步更新。
已有两道缓解：角标文本前缀兜底；整页 ≥10 条却识别不出任何评分时，面板显示改版警告。

## P3 · 年份来自发布名

发布名不含四位年份的条目永远不会命中。2026-09-06 与 09-07 两次实测均 100/100 能提取到，风险很低。
