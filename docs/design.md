# 设计说明

更新时间：2026-09-06

## 目标

M-Team 列表页的高级搜索提供了類別 / 編碼 / 解析度 / 國家 / 製作組 / 標記 / 發佈時間 / 促銷，
但**没有评分和影片年份**（發佈時間是种子发布日，不是影片年份）。
本扩展在客户端补上这两个维度：达标的高亮，不达标的压暗。

## 数据来源

页面是 Ant Design Table 的 SPA，每页 100 条、共 100 页，翻页和排序都是原地重渲染。
列表接口 `POST https://api.m-team.cc/api/torrent/search` 的响应拿不到（内容脚本在隔离世界，
挂不上页面自己的 fetch/XHR），所以**一切数据从 DOM 读**。这也是更简单的路子。

2026-09-06 在 `/browse/movie` 第一页实测 100 条：

| 数据 | 位置 | 覆盖率 |
|---|---|---|
| 豆瓣分 | 行首格里的绿底角标，文本 `豆 7.8` | 99/100（其中 1 条是 `豆 N/A`） |
| IMDb 分 | 行首格里的黄底角标，文本 `IMDB 5.4` | 74/100 |
| 年份 | 发布名里的四位数字 | 100/100 |

### 为什么用背景色类而不是 class 全串

角标 class 里带 emotion 哈希（`css-ypkju9`），站点重新构建就会变。
但 Tailwind 的任意值背景色类是站点写死的语义锚点：

- 豆瓣 `bg-[#007711]`
- IMDb `bg-[#F5C518]`

文本前缀（`豆 ` / `IMDB `）作为兜底，因为站点支持切换语言，前缀可能被翻译掉，
而颜色不会。两个判据都失效时（整页识别不出评分）面板会给出改版警告。

### 年份为什么从发布名取

发布名形如 `Change pas de main AKA Don't Change Hands 1975 Blu-ray 1080p AVC`。
取落在 `1900..(今年+1)` 区间的**最后一个**四位数：

- `1080p` / `2160p` 不在 `19xx|20xx` 模式里，天然排除
- `Blade Runner 2049 2017` 里的 2049 超出上界被挡掉
- `2001 A Space Odyssey 1968` 取靠后的 1968（发布名惯例是片名在前、年份在后）

实测 100 条里没有一条出现多个候选年份。

## 判定

```
命中 = 年份达标 且 分数达标

年份达标 = year !== null && year >= minYear
分数达标 = (豆瓣和 IMDb 都缺) ? false
         : (豆瓣 >= minDouban) || (IMDb >= minImdb)   // 缺失的一侧不参与比较
```

两个评分源取 **或**：只有一个分数的条目（IMDb 覆盖率只有 74%）不该因为缺另一个被漏掉。
年份取不到视为不达标，和「都没评分就不命中」保持一致。

默认 IMDb 7 / 豆瓣 7 / 年份 = 今年 − 5（年份动态计算，不写死）。

## 模块划分

| 模块 | 职责 | 依赖 |
|---|---|---|
| `parser.js` | `parseRow(tr)` → `{title, douban, imdb, year}` | DOM 只读 |
| `filter.js` | `matches(row, cfg)`、`defaults()`、`normalize(raw)` | 纯函数 |
| `panel.js` | 面板 DOM、`chrome.storage.sync` 读写 | DOM + chrome |
| `content.js` | 挂载、MutationObserver、打标记 | 以上全部 |

MV3 内容脚本用不了 ESM，四个文件按顺序挂在 `content_scripts.js` 里共享隔离世界的作用域，
通过 `globalThis.MTF` 命名空间互相引用。这样既能在浏览器里直接跑，也能在 node 里 `require` 做单测，
不需要引入打包器。

## 两个实现上的坑

**左侧色条不能用 inset box-shadow。** 海报图紧贴 `td` 左边缘，inset 阴影画在内容下层会被海报
整条盖住。改成绝对定位的 `::before` 叠在上层（`z-index: 2`）。

**MutationObserver 会被自己触发。** 面板更新命中计数属于 childList 变更，会再次触发 observer，
形成死循环。回调里排掉 target 落在 `.mtf-panel` 内的变更。给行加 `.mtf-hit` 是属性变更，
observer 只订阅 `childList`，不会自激。

## 边界与错误处理

- 解析失败的字段返回 `null`，不返回 `NaN`（`豆 N/A` 是真实存在的情况）
- `豆 0` 是真实分数，不当作缺失
- 设置经 `normalize()` 收敛：分数夹到 0..10，年份夹到 1900..今年+1，空值和非法值回落默认
- `chrome.storage` 不可用时回落默认值，只影响持久化，不影响本页筛选
- 非 `/browse/*` 页面移除面板并清掉标记
- 整页 ≥10 条却一条评分都识别不出 → 面板显示改版警告

## 明确不做

- **不隐藏行**：早期方案是隐藏不达标项，但服务端分页固定每页 100 条，过滤后每页剩余数量不定，
  翻页体验很差。改成高亮 + 压暗后页面结构完全不变。
- **不跨页聚合**：需要在 MAIN world 注入脚本拿鉴权头、自己调 `/api/torrent/search`、做限速和虚拟列表，
  复杂度高且有被站方风控的风险，收益不值。
- **不排序置顶**：会打乱站点自身的排序语义。
